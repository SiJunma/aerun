# Концепция автономных Web Push уведомлений для Aerun

**Статус:** Черновик / Архитектурный концепт  
**Стек:** Go (PocketBase) + React (Vite) + Service Worker (Web Push API)  
**Главная цель:** Обеспечить доставку Push-уведомлений на мобильные устройства и ПК без зависимости от Google/Firebase OAuth2 и тяжелых сторонних SDK.

---

## 1. Архитектурный обзор

Система использует стандарт **Web Push (VAPID)**, встроенный в современные браузеры. Связь между бэкендом форума и устройством пользователя осуществляется через стандартные каналы доставки ОС (Google Play Services / Apple APNs), не требуя активной вкладки браузера или работы сайта в фоновом режиме.

```
[Аэрун VPS (Go)] ──(VAPID HTTP)──> [Push Service (Apple/Google)] ──> [Устройство (iOS/Android)]
```

### Преимущества:
- **Автономность:** Данные подписчиков хранятся в базе PocketBase (`push_subscriptions`).
- **Энергоэффективность:** Сервер не держит постоянных сокетов/соединений с телефонами.
- **Совместимость:** Работает на Android, iOS (через PWA), Windows, macOS, Linux.

## 2. Схема базы данных (PocketBase)

Коллекция: `push_subscriptions`

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `user` | Relation (`users`) | Владелец подписки (каскадное удаление при удалении юзера). |
| `endpoint` | Text (Unique) | Уникальный URL устройства от Push-сервиса браузера. |
| `p256dh` | Text | Публичный ключ шифрования устройства. |
| `auth` | Text | Секретный ключ аутентификации. |
| `user_agent` | Text | Информация об устройстве/браузере (для управления в профиле). |
| `created` / `updated` | Autodate | Стандартные системные поля. |

## 3. Логика на стороне бэкенда (Go)

### 3.1 Ключи VAPID
При первом запуске бэкенд генерирует пару ключей VAPID (или берет из `.env` / `forum_settings`):
- `VAPID_PUBLIC_KEY`: Отдается фронтенду для оформления подписки.
- `VAPID_PRIVATE_KEY`: Хранится только на сервере и используется для подписи отправляемых push-пакетов.

### 3.2 Отправка (Интеграция с Outbox / Event Bus)
При событии (например, новое личное сообщение или ответ в теме):
1. Проверяется признак `isMemberOnline`. Если пользователь активен на сайте, push не отправляется (или отправляется с задержкой).
2. Выбираются все активные `push_subscriptions` для адресата.
3. С помощью Go-библиотеки (например, `github.com/SherClockHolmes/webpush-go`) формируется и отправляется зашифрованный пакет.
4. При получении ошибки `410 Gone` или `404 Not Found` от Push-сервиса подписка автоматически удаляется из БД как недействительная.

## 4. UI/UX: Раздел настроек в профиле пользователя

В настройках профиля (раздел **Уведомления**) добавляется блок управления push-уведомлениями, включающий статус текущего устройства, кнопку включения/выключения и подробную справку-инструкцию.

### 4.1 Статусы устройства в интерфейсе
- 🟢 **Подключено** — Push-уведомления активны на данном устройстве.
- 🟡 **Не настроено** — Поддержка есть, но пользователь еще не нажал «Включить».
- 🔴 **Заблокировано в браузере** — Разрешение отклонено (требуется сброс в настройках браузера).
- ⚪ **Требуется установка (iOS)** — Показывается на iPhone/iPad, если сайт открыт в Safari, а не добавлен на домашний экран.

---

### 4.2 Текст справки и инструкция для пользователей (для вставки в UI)

> ### 🔔 Push-уведомления на мобильных устройствах
> 
> Наш форум отправляет мгновенные уведомления напрямую на ваше устройство без установки сторонних приложений и без передачи личных данных корпоративным сервисам.
> 
> #### 📱 Инструкция для Android:
> 1. Нажмите кнопку **«Включить Push-уведомления»** выше.
> 2. В появившемся системном запросе браузера выберите **«Разрешить»**.
> 3. *Если уведомления не приходят в заблокированном состоянии:* Проверьте настройки Android ➔ *Приложения* ➔ *Ваш браузер* (Chrome/Firefox/Yandex) ➔ *Батарея* ➔ Установите **«Без ограничений»** или включите **«Автозапуск»**.
> 
> #### 🍎 Инструкция для Apple (iPhone / iPad):
> *Apple разрешает отправку Push-уведомлений только для сайтов, сохранённых как веб-приложения (PWA).*
> 1. Откройте сайт **aerun-world.com** в браузере **Safari**.
> 2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана).
> 3. Прокрутите меню вниз и выберите **«На экран «Домой»»** (Add to Home Screen).
> 4. Закройте Safari, откройте иконку **Aerun** с рабочего стола телефона.
> 5. Перейдите в настройки профиля и нажмите **«Включить Push-уведомления»**.
> 
> #### 💻 ПК и ноутбуки (Windows / macOS / Linux):
> Уведомления приходят во всплывающих окнах операционной системы, даже если вкладка форума свёрнута или закрыта (при запущенном браузере).

## 5. Этапы реализации

| # | Шаг | Ответственный модуль | Описание |
|---|---|---|---|
| 1 | **VAPID & Схема БД** | Backend (Go / PB) | Создание коллекции `push_subscriptions`, генератор VAPID-ключей в `forum_settings`. |
| 2 | **Service Worker** | Frontend (`public/sw.js`) | Обработчик событий `push` и `notificationclick` (фоновое открытие нужной темы или диалога). |
| 3 | **UI & Client Hook** | Frontend (React) | Хук `usePushNotifications`, UI-блок в настройках профиля с инструкциями под iOS/Android. |
| 4 | **Worker Отправки** | Backend (Go) | Функция отправки `SendPushNotification(userID, payload)` в системе обработчиков событий (DMs, упоминания). |
| 5 | **Тестирование** | QA / Dev | Проверка доставки в заблокированном состоянии на Android и iOS (PWA). |
