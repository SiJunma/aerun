# I18N.md — локализация интерфейса

> **Статус:** актуально (2026-11-02). Правила UI: `.agent/rules/ui_standards.md`.

## Как это работает

- Функция `t(key)` доступна через `I18nProvider` (`src/contexts/I18nProvider.jsx`).
- Словарь: `src/i18n/dictionary.js` — пары EN/RU для всех ключей интерфейса.
- Языки: английский и русский; архитектура расширяемая (roadmap — community-переводы).

## Правила

1. **Никаких хардкод-строк в UI** — только `t()`.
2. **Новая фича = новые ключи сразу** в обоих языках (EN + RU) в `dictionary.js`; расхождение словарей — баг.
3. **Терминология консистентна** по всему приложению (одно понятие — один ключ).
4. При переименовании ключа — grep по всем использованиям до удаления старого.

## Добавление нового языка

1. Добавить секцию словаря в `src/i18n/dictionary.js` (полный набор ключей).
2. Зарегистрировать язык в списке выбора (settings/ThemeProvider, где хранится `settings.language`).
3. Убедиться, что дата/время форматируются через utils (`src/utils/dates` + date-fns-tz), а не через локаль по умолчанию.
4. Проверить длину строк: RU длиннее EN — кнопки/лейблы не должны ломать вёрстку в трёх темах.
